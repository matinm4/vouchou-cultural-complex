## 📖 درباره پروژه

**«ووچو»** در گویش اصیل لری زاگرس‌نشینان به‌معنای **«آنجا»**ست — مقصدی آشنا، قراری ماندگار و پاتوقی گرم برای ساکنان **محله لبنان گچساران**؛ یکی از محروم‌ترین بافت‌های کوهپایه‌ای که پس از جنگ تحمیلی شکل گرفت.

این مجموعه فرهنگی با ایده **خوداتکایی اقتصادی** (نانوایی سنگک + کافه + کتاب‌فروشی در جداره خیابان) بدون اتکا به بودجه دولتی، به کانون نورانی و امن محله تبدیل شده است.

| مشخصات | مقدار |
|---|---|
| 📐 مساحت زمین | ۱۱۵ مترمربع |
| 🏢 زیربنا | ۱۴۰ مترمربع |
| 🎨 معمار | محمدرضا تاجگردون |
| 🤝 کارفرما | مؤسسه مشک و ملار |

## 🎯 امکانات ارائه سه‌بعدی

- 🖼️ **۱۶ اسلاید** همگام با دوربین سه‌بعدی (حالت شب 🌙 / روز ☀️)
- 🎮 **گردش آزاد** دور مدل، حالت **دیاگرام (X-Ray)** و پخش خودکار
- ⌨️ کنترل کامل با کیبورد (`←` `→` `F` تمام‌صفحه `G` فهرست `H` فقط مدل)
- 📋 گالری شیت‌ها با **دانلود PDF چاپی** و نسخه وب تعاملی
- 📱 پشتیبانی از سوایپ لمسی موبایل

## 🚀 اجرا (بدون نصب هیچ‌چیز!)

> نه Node.js، نه Python، نه بیلد — فقط یک مرورگر کافیست.

**روش ۱ — دابل‌کلیک (ویندوز):**

```
start-presentation.bat
```

**روش ۲ — مستقیم:**

`index.html` را در مرورگر باز کنید.

## 📁 ساختار پروژه

```
site/
├── index.html          ← ارائه سه‌بعدی (صفحه اصلی)
├── sheets.html         ← گالری و دانلود شیت‌ها
├── sheet1.html         ← شیت ۱: کانسپت و تحلیل فرم
├── sheet2.html         ← شیت ۲: پلان‌ها، مقاطع و اتمسفر
├── css/                ← استایل ارائه
├── js/                 ← داده اسلایدها، صحنه Three.js، کنترلر
├── assets/             ← مدل‌ها، تصاویر، دیاگرام‌ها (لوکال)
├── files/              ← PDF و JPG چاپی شیت‌ها
└── start-presentation.bat
```

## 🛠️ تکنولوژی‌ها

- **Three.js r128** (لوکال، بدون CDN) — مدل حجمی procedurally ساخته‌شده با Canvas Texture
- HTML / CSS / Vanilla JS — صفر وابستگی، صفر بیلد
- فونت وزیرمتن با fallback به Tahoma (کارکرد کامل آفلاین)
